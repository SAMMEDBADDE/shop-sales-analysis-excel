# Vrinda Store Data Analysis – Microsoft Excel

## Project Overview

This project analyzes Vrinda Store's 2022 sales data using Microsoft Excel to understand sales performance, customer demographics, order status, sales channels, product categories, and geographic performance.

The project uses Excel-based data analysis techniques to transform raw sales data into meaningful business insights and an annual sales report/dashboard.

## Dataset

The main dataset contains **31,047 sales records** with information including:

- Order ID
- Customer ID
- Gender
- Age
- Age Group
- Order Date
- Month
- Order Status
- Sales Channel
- SKU
- Product Category
- Size
- Quantity
- Amount
- Shipping City
- Shipping State
- Postal Code
- Country
- B2B indicator

The dataset contains transactions from the **2022 sales period**.

## Project Objectives

The analysis was performed to:

- Understand overall sales performance
- Analyze monthly sales and order trends
- Compare sales across different channels
- Analyze customer demographics by age and gender
- Identify top-performing states
- Analyze order status such as delivered, returned, cancelled, and refunded
- Compare sales contribution by gender
- Understand product/category performance
- Build an annual sales report and dashboard

## Analysis Performed

### 1. Channel Analysis

Analyzed sales activity across major sales channels including:

- Amazon
- Myntra
- Flipkart
- Ajio
- Nalli
- Meesho
- Others

### 2. Customer Demographic Analysis

Analyzed customer distribution based on:

- Gender
- Age
- Age Group

Age groups were categorized into:

- Teenager
- Adult
- Senior

### 3. Sales vs Orders Analysis

Analyzed monthly sales amount and order volume to understand how sales activity changes throughout the year.

### 4. Gender Analysis

Compared sales contribution between:

- Women
- Men

### 5. Order Status Analysis

Analyzed different order outcomes including:

- Delivered
- Returned
- Cancelled
- Refunded

### 6. Geographic Analysis

Analyzed sales performance across Indian states and identified the highest-performing states based on sales amount.

### 7. Annual Sales Report

Created a consolidated annual report combining key sales and customer insights into a visual Excel report/dashboard.

## Key Business Questions

The project focuses on questions such as:

- Which sales channels generate the most orders?
- Which months show stronger sales activity?
- Which customer age groups contribute most to sales?
- How does sales contribution differ between men and women?
- Which states generate the highest sales?
- What proportion of orders are delivered, returned, cancelled, or refunded?
- Which product categories contribute significantly to sales?
